# viralstanclinicportfolio

Viralstan's healthcare marketing portfolio for clinics and doctors. Built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Editing content

All text (services, specialities, case studies, testimonials, reels, FAQs and contact details) lives in `src/data/content.js`.
Videos go in `public/reels/<id>.mp4` with a poster image `public/reels/<id>.jpg`.

To save contact-form leads to a Google Sheet (downloadable as Excel), follow the steps in `google-sheet/form-to-sheet.gs`.
